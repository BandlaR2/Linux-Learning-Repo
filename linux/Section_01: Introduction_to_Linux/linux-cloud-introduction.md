# Introduction to Linux for Cloud Engineers

## Why Learn Linux?
- No need to master all Linux commands.
- Around 15–16 commands are commonly used in cloud environments.
- Learn through hands-on projects and real-world examples.

## Computer Components

### Hardware
- CPU → Brain of computer
- RAM → Temporary memory
- Storage → HDD, SSD
- Input Devices → Keyboard, Mouse
- Output Devices → Monitor, Printer

### Software
- Operating System (OS)
- Applications
- Drivers
- Utilities

## Linux History
- Created by Linus Torvalds in the early 1990s.
- Open-source operating system.
- Used from personal systems to cloud data centers.

## Popular Linux Distributions

| Distribution | Use |
|-------------|------|
| Ubuntu | Beginners, cloud servers |
| RHEL | Enterprises |
| Fedora | Developers |
| Debian | Stability |
| CentOS | Web hosting |
| Kali Linux | Cybersecurity |
| Amazon Linux 2 | AWS cloud |

## Why Linux for Cloud?

- Open-source and free
- Supports multiple users
- Secure and stable
- High performance and reliability

## Linux Architecture

1. Hardware
2. Kernel → Core of Linux
3. Shell → Executes commands
4. Daemons → Background services
5. Applications & Utilities

## Linux File Types

| File Type | Example |
|------------|----------|
| Data Files | .txt, .jpg |
| Configuration Files | /etc/passwd |
| Executable Files | /bin/bash |
| Daemon Files | sshd, httpd |
